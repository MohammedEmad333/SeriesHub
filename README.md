# SeriesHub

SeriesHub is a Flutter-first TV series app focused on Arabic, subtitled, and dubbed series.

## Goals

- Arabic-first RTL experience
- Arabic, subtitled, and dubbed catalogs
- Seasons and episodes
- Search and filters
- Favorites and watch history
- Continue watching
- Downloads for authorized/offline content
- Extensible provider architecture
- Modern video player

> SeriesHub does not bundle copyrighted streams. Providers should point only to content the user is authorized to access.

## Architecture

Feature-first Flutter structure with provider adapters separated from UI and domain logic.

See `docs/ARCHITECTURE.md` and `docs/ROADMAP.md`.
